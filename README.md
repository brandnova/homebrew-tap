# Homebrew tap for Perigee Files

Install on macOS or Linux:

    brew install brandnova/tap/perigee

or add the tap first:

    brew tap brandnova/tap
    brew install perigee

This repository is updated automatically by the release process of
[perigee-files](https://github.com/brandnova/perigee-files). Please don't edit the formula by hand.
